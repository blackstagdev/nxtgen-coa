1. **Completed COA examples:** Use these to identify the fields, value formats, units, result layouts, and placement required for that test type.
2. **Blank COA templates:** Use these as the background templates for generating completed COAs.

- Create an inventory of the visible fields.
- Separate shared COA metadata from test-specific fields.

## 6. Generate completed COA images

When a staff member fills out a COA form, the application must generate a new WEBP image by placing the entered information onto the correct blank template.

Requirements:

- Preserve the original template’s dimensions, aspect ratio, branding, and visual quality.
- Match text placement, alignment, font sizing, and formatting to the completed reference.
- Handle multiline values and long text without clipping or overlapping other fields.
- Preserve scientific symbols, units, and numeric precision.
- Validate required information before allowing publication.
- Let staff inspect the generated image before publishing.
- Retain structured form data alongside the generated image.
- Track generated versions so an updated report can be traced to its underlying data.

Avoid destructive overwriting of published images. Use versioned object keys and an explicit published-version reference.

A generated image should reproduce entered results; it must not calculate or infer scientific conclusions unless an authoritative rule is supplied in the project.
